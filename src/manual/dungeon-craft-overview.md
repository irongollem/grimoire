**Dungeon Craft** is a hub of six preparation tools for designing complex environments and drawing the maps that go with them. Find it under **Compendium → Dungeon Craft** in the sidebar (`/dungeon-craft`). It isn't just for dungeons: use it any time you want scripted hazards, interactive puzzles, random tables, a loot drop, or a tile-based map.

## The six tabs

### Features

Secret doors, hidden passages, treasure chests, concealed alcoves, moving walls, and other environmental secrets. Each feature has detection DCs, a trigger mechanism, and a "what's inside" description, and can optionally be dropped into one or more Atlas rooms. See [Dungeon Craft: Features](#dungeon-craft-features).

### Traproom

Full mechanical trap definitions: type, trigger, detection and disarm DCs, damage entries, save DCs, and CR. A built-in **CR Advisor** helps you balance traps to match your encounter difficulty, and an AI **Generate** button can draft one from a one-line concept. See [Dungeon Craft: Traps](#dungeon-craft-traps).

### Enigmarium

Rich puzzle definitions with setup text, skill checks, ordered hints you reveal one at a time, a locked solution, and outcomes for success and failure. Reveal a puzzle to specific party members and they see it live in the Player Portal. See [Dungeon Craft: Puzzles](#dungeon-craft-puzzles).

### Roll Tables

Custom random tables for any die (d4 through d100). Roll directly in Grimoire and see the result. Link table entries to encounters: clicking a rolled entry opens the encounter sheet directly. See [Dungeon Craft: Roll Tables](#dungeon-craft-roll-tables).

### Loot Tables

Define loot drop tables with specific items, random-rarity items, and currency pools. Roll for loot, preview results, and drop the chest directly to campaign chat for players to claim. See [Dungeon Craft: Loot Tables](#dungeon-craft-loot-tables).

### Cartographer

Grimoire's tile-based map editor, embedded here as a sixth tab so map-drawing sits next to the rest of your dungeon prep. It's the same editor as the standalone **Publish → Cartographer** entry in the sidebar (desktop only): both open the same list of maps. See [Cartographer: Overview](#cartographer-overview).

## Populate Examples

Features, Traproom, Enigmarium, and Roll Tables each have a **Populate Examples** button (labelled **Populate Traproom** on the Traps tab) that seeds curated template content: pre-built traps, puzzles, features, and tables to use as-is or as a starting point. It's safe to run more than once, since it skips anything you've already got by name. Loot Tables and Cartographer have no populate button.

## AI generators

Traproom, Enigmarium, Roll Tables, and Loot Tables each have a **Generate** button that opens an AI-assisted generator for that entity type. Features has no AI generator: create those by hand. Generation is Pro-gated and spends AI credits (or runs free if your campaign uses your own API key); each generator's page describes its cost and inputs.

## Placing things in your world

Traps, Features, Roll Tables, and Loot Tables can each be dropped into one or more Atlas rooms: the same trap template can sit in several places, and a room's own page lists everything placed there. Each entity's detail page has a **Placed In** panel for this; see [Sites: Maps, Rooms & Running a Dungeon](#sites-maps-rooms-running-a-dungeon) for the reverse view (a room listing what's placed in it) and for how the Cartographer's Publish step can place things automatically from a drawing. Puzzles work differently: a puzzle names its own **Location** and **Dungeon Feature** anchor directly on its own page, since a puzzle is a one-off instance rather than a reusable template.

## Moving things between campaigns

On the Traproom, Enigmarium, Roll Tables, and Loot Tables tabs, click **Select** to enter multiple-selection mode, then use the bar that appears to **Move** or **Copy** the selected entries to a different campaign you DM. Each entity's own detail/editor page also has a **Copy to campaign…** action for one at a time. Features has no bulk move/copy on its grid.

## Campaign scope

Every entity in Dungeon Craft carries a **Scope** control: **General** (all campaigns) or a specific campaign. General entries show up everywhere; a scoped one only shows while that campaign is active. New entries default to your active campaign.
