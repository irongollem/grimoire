**Dungeon Craft** (`/dungeon-craft`) is a hub of five preparation tools for designing complex environments. It isn't just for dungeons — use it any time you want scripted hazards, interactive puzzles, random tables, or hidden secrets.

## The five tabs

### Dungeon Features

Secret doors, hidden passages, treasure chests, concealed alcoves, moving walls, and other environmental secrets. Each feature has detection DCs, a trigger mechanism, and a "what's inside" description.

→ _See Dungeon Craft: Features_ for the full reference.

### Traps

Full mechanical trap definitions — type, trigger, detection and disarm DCs, damage entries, save DCs, and CR. A built-in **CR Advisor** helps you balance traps to match your encounter difficulty.

→ _See Dungeon Craft: Traps_.

### Puzzles

Rich puzzle definitions with setup text, skill checks, ordered hints you reveal one at a time, a locked solution, and outcomes for success and failure. Share puzzles to the player portal so players can read clues and see revealed hints in real time.

→ _See Dungeon Craft: Puzzles_.

### Roll Tables

Custom random tables for any die (d4 through d100). Roll directly in Grimoire and see the result. Link table entries to encounters — clicking a rolled entry opens the encounter sheet directly.

→ _See Dungeon Craft: Roll Tables_.

### Loot Tables

Define loot drop tables with specific items, random-rarity items, and currency pools. Roll for loot, preview results, and drop the chest directly to the campaign chat for players to claim.

→ _See Dungeon Craft: Loot Tables_.

## Populate Examples

Most tabs have a **Populate Examples** button that seeds curated template content — a library of pre-built traps, puzzles, features, and tables to use as-is or as a starting point. The import is idempotent — safe to run more than once.
