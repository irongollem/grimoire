Grimoire is a full-stack campaign manager for Dungeons & Dragons 5e. It gives you — the Dungeon Master — a single place to build your world, run sessions, and let your players participate in real time.

## What Grimoire does

**Before the session:** Write session notes, track quests, build NPCs and locations, design encounters, and create monsters and spells. The preparation tools work together — an NPC you create can appear in an encounter, link to a quest, and be shared with a specific player automatically.

**During the session:** Run live combat with the Encounter Runner. HP changes, conditions, and monster discoveries sync to your players' devices instantly. Players see only what you've revealed.

**Between sessions:** Players manage their own characters — spells, inventory, crafting — and update their journals. Everything stays current for next session without any bookkeeping.

## The two sides of Grimoire

| DM Side                             | Player Portal                                |
| ----------------------------------- | -------------------------------------------- |
| Full read/write access              | Role-gated, players only see their view      |
| Campaign settings, members, invites | Character sheet, inventory, spells           |
| World-building tools                | Quest log, factions, atlas (shared portions) |
| Encounter builder & runner          | Live combat panel                            |
| Scriptorium, Card Forge, Mint       | Crafting, bestiary, journal                  |

Players join via an invite link you generate. Once joined, they see the Player Portal automatically — they cannot access DM screens.

## Where to begin

If you're running Grimoire for the first time:

1. **Create a campaign** — set a name, world setting, and calendar system.
2. **Populate your world** — use the "Populate from Setting" buttons in Atlas and Factions to seed iconic locations and organisations instantly.
3. **Add your players** — generate invite links in Campaign Settings → Invites.
4. **Import content** — import SRD monsters, spells, and items with single clicks in each section.

The rest of this manual covers every tool in depth.
