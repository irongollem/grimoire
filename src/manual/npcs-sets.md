An NPC Set is a named playlist of NPCs — the cast for a session, a faction's leadership, the residents of one tavern — that you can manage and print together instead of hunting them down one at a time.

## Creating a set

Click **New Set** on the NPC Sets list (`/npcs/sets`). Name it, then add NPCs to the playlist from your existing roster. A set only stores references to NPCs — nothing about the NPC itself is duplicated or locked, so editing an NPC anywhere updates every set it belongs to.

## Exporting to the Card Forge

Click **Export** on a set's card to load every member straight into the Card Forge and jump you there — ready to print the whole cast as physical or virtual cards in one pass, instead of adding each NPC individually.

## Deleting a set

Deleting a set only removes the playlist. The NPCs themselves are not affected and remain in your NPC Tracker.
