An NPC Set is a named playlist of NPCs — the cast for a session, a faction's leadership, the residents of one tavern — that you can manage and print together instead of hunting each one down individually. Open it from the NPC Tracker's **Sets** header button, or at `/npcs/sets`.

## Key ideas

A set only stores references to NPCs — nothing about the NPC itself is duplicated or locked. Editing an NPC anywhere updates every set it belongs to, and deleting an NPC just drops it out of any set it was in.

## Creating a set

1. Click **New Set**.
2. Enter a **Name** (required) and optional **Notes**.
3. Search and check NPCs in the picker below — the running count reads "N selected."
4. Click **Create set**.

## Editing a set

Click the edit (pencil) icon on a set's card to reopen the same form, pre-filled, with the title "Edit set." Add or remove NPCs the same way, then click **Save**.

If a set contains NPCs that have since been deleted, the card notes how many were "removed" and no longer resolve.

## Exporting to the Card Forge

Click **Export to Card Forge** on a set's card (disabled if the set is empty) to load every current member straight into the Card Forge and jump you there — ready to print the whole cast as physical or virtual cards in one pass, instead of adding each NPC individually.

## Deleting a set

Click the delete (trash) icon on a set's card and confirm. Deleting a set only removes the playlist — the NPCs themselves are not affected and remain in your NPC Tracker.

## What your players see

Players never see NPC Sets — it's a DM-only prep and printing tool.
