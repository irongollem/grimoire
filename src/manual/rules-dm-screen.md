The **DM Screen** tab in the Reliquary (**Compendium → Reliquary**, `/rules` → DM Screen) is a built-in, always-available quick-reference: the tables you'd otherwise keep on a physical screen at the table.

## What's covered

Switch between five sections with the button row at the top, then between that section's reference tables underneath:

- **Combat**: actions in combat, common bonus actions, common reactions, cover, conditions, death saving throws, creature size & space, object AC, object HP, underwater combat.
- **Ability Checks**: skills by ability, difficulty class bands, common contests, carrying capacity, jumping.
- **Environment**: light & vision, exhaustion, falling, travel pace, food & water, resting.
- **Spellcasting**: spell slot levels by class level, concentration.
- **Equipment & Services**: lifestyle expenses per day, food/drink/lodging, services, mounts, waterborne vehicles, donning & doffing armor.

This reference is static: it isn't affected by your campaign's custom rules and needs no setup. For house rules that override or extend the SRD, use the **Custom Rules** tab instead.
